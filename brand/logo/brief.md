# Kopwang — ไอเดียโลโก้ใช้ได้ทุกแพลตฟอร์ม

ไฟล์นี้สรุปทิศทางโลโก้ 3 แบบที่ต่อยอดจากตัวตนแบรนด์ใน `brand/brand-kit.md`
พร้อมตัวอย่างจริงในโฟลเดอร์นี้ (PNG 1024 / PNG 64 / SVG) เพื่อให้เลือกก่อนผลิตชุดเต็ม

## 1. โจทย์ที่ต้องแก้

| ข้อจำกัด | ผลต่อการออกแบบ |
|---|---|
| อวตาร Facebook Page, TikTok, IG, YouTube ถูกครอปเป็น **วงกลม** เหลือเล็กสุด ~40px | สัญลักษณ์ต้องอยู่ในวงกลมและอ่านได้ตอนจิ๋ว — **ห้ามใส่ตัวอักษรไทยหรือคำยาวในอวตาร** |
| ใช้ร่วม Shopee, Line OA, favicon, เอกสาร, สติกเกอร์ | ต้องมีเวอร์ชันสีเดียว (ดำ/ขาว/ทอง) และพื้นหลังโปร่งใส |
| แบรนด์ห้ามสัญญารายได้/รวยเร็ว | ห้ามใช้ธนบัตร เหรียญ กราฟพุ่ง ตัวเลขกำไร — ภาพต้องสื่อ "ระบบ/ลำดับ/เวลา" ไม่ใช่ "เงิน" |
| กลุ่มเป้าหมาย 25-45 ปี ภาษาพูดตรง ไม่โอ้อวด | รูปทรงเรขาคณิตเรียบ ไม่ไล่เฉด ไม่เงานุ่มแบบสตาร์ทอัพ |

## 2. สีและตัวอักษร (ใช้ร่วมกับหน้าเว็บเดิม)

| บทบาท | สี | ใช้งาน |
|---|---|---|
| Ink | `#14161C` | พื้นอวตาร/พื้นเข้ม |
| Amber | `#FFB020` | สีหลักของสัญลักษณ์ (ตัว K / ขั้น / ลิ่มเวลา) |
| Cream | `#F5EFE2` | ตัวอักษรรองบนพื้นเข้ม, เส้นนาฬิกา |
| Mint | `#25C281` | ใช้ ≤10% ของพื้นที่ เฉพาะจุด "ทำแล้ว/วันนี้" |

- **อวตาร:** สัญลักษณ์ล้วนบนพื้น Ink — ไม่มีคำว่า Kopwang
- **เวิร์ดมาร์ก:** `Kopwang` ตัวหนา + บรรทัดเล็ก `ระบบสร้างรายได้ใน 30 วัน`
  ฟอนต์ไทย: IBM Plex Sans Thai / Noto Sans Thai (SemiBold) — ตัว K ในเวิร์ดมาร์กใช้รูปเดียวกับสัญลักษณ์เพื่อความต่อเนื่อง
- **ระยะห่างปลอดภัย:** รอบสัญลักษณ์ ≥ 1/2 ความสูงของตัว K และอยู่ในวงกลม Ø 84% ของอวตาร

## 3. สามทิศทาง

### A. K-Bar — ตัว K จาก 3 เส้น (`k-bar.svg`)

| | |
|---|---|
| แนวคิด | ตัว K ที่ปลายแขนทั้งสองข้างทำมุมเป็นลูกศรชี้ไปข้างหน้า = "ลำดับที่ไม่ต้องคิดใหม่ทุกวัน" |
| จุดแข็ง | อ่านได้ตั้งแต่ 24px, ทำสีเดียวได้, ต่อยอดเป็น favicon/ลายน้ำ/สติกเกอร์ได้ทันที |
| จุดอ่อน | เรียบเกินไปถ้าไม่คุมสีให้ดี — ต้องกันคนอื่นใช้ K คล้ายกันด้วยสี Amber |
| เหมาะกับ | **อวตารหลักทุกแพลตฟอร์ม** |

### B. Day Steps — สามขั้น ascending (`day-steps.svg`)

| | |
|---|---|
| แนวคิด | 30 วันคือการไต่ทีละขั้น ไม่ใช่กระโดด — จุด Mint ด้านบนคือ "วันที่ทำสำเร็จ" |
| จุดแข็ง | เล่าเรื่องระบบ/ความคืบหน้าได้โดยไม่ต้องมีตัวอักษร เหมาะกับปกคลิปและภาพประกอบโพสต์ |
| จุดอ่อน | เสี่ยงอ่านเป็น "กราฟกำไร" ซึ่งขัดจุดยืนไม่สัญญารายได้ — ถ้าใช้ ต้องมีแคปชันกำกับความหมาย |
| เหมาะกับ | ภาพปกเพจ/ปกคลิป, ภาพโพสต์สรุปรายสัปดาห์ |

### C. One Hour — วงนาฬิกา + ลิ่ม 1 ชั่วโมง (`one-hour.svg`)

| | |
|---|---|
| แนวคิด | คำสัญญาหลัก "วันละ 1 ชั่วโมง" แปลงเป็นภาพ: ลิ่ม Amber 1 ชั่วโมงบนหน้าปัด |
| จุดแข็ง | แตกต่างจากโลโก้คอร์สออนไลน์ทั่วไป และผูกกับจุดขายได้ตรงที่สุด |
| จุดอ่อน | รายละเอียดเยอะกว่า A เล็กน้อย — ที่ 32px เส้นบางลงต้องเพิ่มน้ำหนักเส้นอีก ~10% |
| เหมาะกับ | แคมเปญ "1 ชั่วโมงพอไหม", ภาพหน้าปก, สติกเกอร์ Line |

### สรุปที่แนะนำ

ใช้ **A เป็นอวตารหลัก** (อ่านง่ายที่สุดและปลอดภัยต่อการตีความ)
เก็บ **C ไว้เป็นมาสคอตแคมเปญ** เวลาพูดถึง "วันละ 1 ชั่วโมง" และใช้ **B เฉพาะภาพปก/สรุปรายสัปดาห์**
ถ้าอยากได้โลโก้ที่ "เล่าเรื่อง" มากกว่า "จำง่าย" ให้สลับ A กับ C เป็นตัวหลัก — แต่ต้องยอมเสียความคมตอนย่อเหลือ 40px

## 4. สเปกไฟล์ที่ต้องมีก่อนอัปทุกแพลตฟอร์ม

| ไฟล์ | ขนาด | ใช้ที่ |
|---|---|---|
| `avatar-*.png` / `.svg` | 1024×1024 | อัปโหลดต้นฉบับ (Facebook, TikTok, IG, YouTube, Line OA) |
| `avatar-*-64.png` | 64×64 | ทดสอบ favicon/อวตารขนาดเล็ก |
| `mark-*-transparent.png` | 1024×1024 โปร่งใส (Amber/Cream) | ลายน้ำคลิปพื้นเข้ม, สติกเกอร์ |
| `mark-*-light.png` | 1024×1024 โปร่งใส (Ink) | งานพิมพ์พื้นขาว/ครีม, เอกสาร |
| เวิร์ดมาร์กแนวนอน | กว้าง ≥ 1200px | ปกเพจ, หน้าปกคลิป, ใบเสนอราคา |
| เวอร์ชันสีเดียว | ดำ / ขาว / Amber | งานพิมพ์, สกรีน, ตราประทับ |

## 5. ข้อห้ามในการนำไปใช้

- ห้ามย่ออวตารแล้วใส่คำว่า "Kopwang" หรือ "30 วัน" ต่อท้าย — ให้ใช้เวิร์ดมาร์กแยก
- ห้ามใส่เงา ไล่สี หรือขอบเรืองแสง เพราะจะแตกตอนบีบอัดของแพลตฟอร์ม
- ห้ามวางสัญลักษณ์ชิดขอบเกินระยะปลอดภัย หรือครอปตัดแขน K
- ห้ามใช้สีแดง/เขียวแบบกราฟหุ้นในโพสต์ที่เกี่ยวกับรายได้
- ห้ามใช้ภาพธนบัตร เหรียญ หรือตัวเลขกำไรเป็นองค์ประกอบโลโก้
