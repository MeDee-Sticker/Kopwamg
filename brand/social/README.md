# Kopwang — ชุดภาพ 3 ช่องทาง (Facebook · TikTok · Shopee)

ชุดภาพชุดเดียวที่ใช้ร่วมกันทั้งสามช่องทาง: อวตารสัญลักษณ์ล้วน หน้าปกที่ปรับตามสัดส่วนของแต่ละแพลตฟอร์ม
และแบนเนอร์ร้าน Shopee — ทุกไฟล์สร้างจากเรขาคณิตเดียวกับโลโก้ K-Bar และสีจาก `brand/brand-kit.md`

ไฟล์ทั้งหมดในโฟลเดอร์นี้ **สร้างใหม่ได้ด้วยสคริปต์** อย่าแก้ PNG ด้วยมือ ให้แก้คำพูด/ขนาดใน `spec.json`
แล้วรันตัวสร้างใหม่ (จะอัปเดต `manifest.json` ให้เอง)

### ไฟล์ต้นฉบับ SVG (แก้ข้อความได้)

หน้าปกและแบนเนอร์ทุกไฟล์มี **SVG ชื่อเดียวกันวางข้าง PNG** — ข้อความไทยทุกบรรทัดเป็น `<text>` จริง
ไม่ถูกแปลงเป็น path จึงแก้คำพูด ขนาด หรือสีได้ใน Illustrator / Figma / Inkscape

| ไฟล์ SVG | ใช้แก้ |
|---|---|
| `cover/facebook-cover-851x315.svg` | หน้าปกเพจ Facebook |
| `cover/shopee-cover-1200x675.svg` | Shop Cover |
| `banner/shopee-shop-banner-1200x300.svg` | Shop Banner |
| `cover/tiktok-video-cover-1080x1920.svg` | ปกคลิป TikTok |

- ชื่อเลเยอร์/องค์ประกอบ: `wordmark`, `tagline`, `promise`, `cta-label`, `day-grid`, `k-mark`
- สัญลักษณ์ K เป็นเส้นเวกเตอร์ (`<path>`) ไม่ใช่ตัวอักษร — ย่อ/ขยายได้โดยไม่แตก
- SVG อ้างฟอนต์แบบ path สัมพัทธ์ `../../fonts/NotoSansThai.ttf` (OFL) ถ้าโปรแกรมเปิดแล้วฟอนต์ไม่ถูกโหลด
  ให้ติดตั้ง `brand/fonts/NotoSansThai.ttf` ในเครื่องก่อน ข้อความจะได้ไม่ไหลเป็นฟอนต์อื่น
- SVG เป็น **ต้นฉบับสำหรับแก้ต่อ ไม่ใช่ไฟล์อัปโหลด** — อัปโหลดเฉพาะ PNG ที่ผ่านเทสต์
- ถ้าแก้ข้อความถาวร ให้แก้ `spec.json` แล้วรันตัวสร้างทั้งสองตัว (PNG + SVG) เพื่อให้ทุกไฟล์ตรงกัน

## 2. ขั้นตอนอัปโหลด

### Facebook Page

1. ไปที่เพจ → **แก้ไขโปรไฟล์** → อัปโหลด `facebook-profile-1024.png`
2. **ภาพหน้าปก** → อัปโหลด `facebook-cover-851x315.png` → ตรวจตัวอย่างทั้งเดสก์ท็อปและมือถือ
   ก่อนกดบันทึก (Facebook ให้เลื่อน/ย่อภาพ — อย่าเลื่อนจนข้อความถูกตัด)
3. รูปโปรไฟล์จะทับมุมซ้ายล่างของหน้าปกบนเดสก์ท็อป — ไฟล์นี้ออกแบบให้ข้อความเริ่มที่ x = 200 px แล้ว
   จึงไม่ถูกทับ แต่ยังควรตรวจตัวอย่างจริงอีกครั้ง

### TikTok

1. โปรไฟล์ → **แก้ไขโปรไฟล์** → เปลี่ยนรูปภาพ → `tiktok-profile-200.png`
2. ตอนอัปโหลดคลิป → **เลือกปก** → อัปโหลด `tiktok-video-cover-1080x1920.png`
3. ตรวจว่าข้อความหลักไม่ถูกปุ่มด้านขวาและแคปชันด้านล่างบังในหน้าพรีวิว

### Shopee

1. Seller Centre → **ข้อมูลร้านค้า** → โลโก้ร้าน → `shopee-shop-logo-500.png`
2. **ตกแต่งร้าน** → Shop Cover → `shopee-cover-1200x675.png`
3. **ตกแต่งร้าน** → Shop Banner → `shopee-shop-banner-1200x300.png`
4. Shopee แต่ละประเทศอาจกำหนดขนาด/การครอปต่างกันเล็กน้อย — ดูพรีวิวใน Seller Centre ก่อนบันทึกทุกครั้ง

## 3. กฎที่ใช้ร่วมกันทั้ง 3 ช่องทาง

- สีจาก `brand/brand-kit.md` เท่านั้น: Ink `#14161C`, Amber `#FFB020`, Cream `#F5EFE2`, Mint `#25C281`
- Mint ใช้ ≤ 10% ของพื้นที่ และใช้เฉพาะจุด "ทำแล้ว/วันสุดท้าย" (ในชุดนี้คือขีดวันที่ 30)
- อวตารเป็นสัญลักษณ์ล้วน ห้ามใส่ชื่อแบรนด์หรือคำยาว เพราะจะถูกครอปเป็นวงกลมและเล็กลงเหลือ ~40 px
- ไม่มีธนบัตร เหรียญ กราฟกำไร หรือลูกศรพุ่งขึ้น — ภาพสื่อ "ระบบ/ลำดับ/เวลา" ไม่ใช่ "เงิน"
- ไม่มีคำสัญญารายได้: ห้าม "รวย" "รวยเร็ว" "การันตีรายได้" "รับประกันรายได้" "รายได้แน่นอน"
- ข้อความทุกชิ้นอ่านออกเมื่อย่อ: หน้าเพจเห็นข้อความหลักได้ก่อนถูกตัด "ดูเพิ่มเติม"

## 4. สร้างใหม่ / แก้คำพูด

แก้ข้อความหรือขนาดใน `brand/social/spec.json` (ไม่ใช่ใน PNG) แล้วรัน:

```bash
# ต้องมี Pillow (และ numpy สำหรับเทสต์)
python3 -m pip install pillow numpy

# ตรวจว่าฟอนต์ไทยถูก shaping ถูกต้อง (ต้องได้ True)
python3 -c "from PIL import features; print(features.check('raqm'))"

# สร้างภาพทั้งหมด + manifest.json
python3 scripts/build_brand_assets.py

# สร้าง/อัปเดต SVG ต้นฉบับของหน้าปกและแบนเนอร์ (ต่อจาก PNG)
python3 scripts/build_brand_svg.py

# ตรวจขนาด โซนปลอดภัย สี คำต้องห้าม และความสม่ำเสมอของอวตาร
python3 tests/brand_assets_test.py

# ตรวจ SVG: ข้อความเป็น text จริง, คำพูด/ฟอนต์ตรงสเปก และตำแหน่งตรงกับ PNG
python3 tests/brand_svg_test.py
```

`tests/brand_svg_test.py` ตรวจโครงสร้างและข้อความได้ทันที ส่วนการเทียบตำแหน่งกับ PNG (±3 px)
จะทำเมื่อมี `resvg` ใน PATH (เช่น `~/.local/bin/resvg --use-font-file brand/fonts/NotoSansThai.ttf`)
ถ้าไม่มี จะรายงานเป็น SKIP ไม่ใช่ PASS

- ฟอนต์: `brand/fonts/NotoSansThai.ttf` (SIL Open Font License 1.1 — ดู `brand/fonts/OFL.txt`)
  ตัวแปรน้ำหนัก 400/500/600/700 ใช้ฟอนต์เดียวกันทั้งไทยและอังกฤษ
- ถ้า `raqm` เป็น `False` สระ/วรรณยุกต์ไทยจะวางผิดตำแหน่ง — ติดตั้ง Pillow เวอร์ชันที่มี libraqm ก่อนสร้างภาพ
- ตัวสร้างจะคำนวณ `content_bbox` ของแต่ละภาพและบันทึกลง manifest เพื่อให้เทสต์ตรวจโซนปลอดภัยซ้ำได้

รันเทสต์ชุดนี้ควบกับด่านอื่นของโปรเจกต์:

```bash
python3 tests/content_draft_test.py
python3 tests/dashboard_api_test.py
node tests/dashboard_smoke.mjs
```

## 5. อ้างอิงขนาดและข้อจำกัด

- Facebook: หน้าปก 851×315 และโหลดเร็วที่สุดเมื่อต่ำกว่า 100 KB — [Facebook Help](https://www.facebook.com/help/125379114252045)
  (ไฟล์นี้ 38 KB) · โซนปลอดภัยกลาง 640×312 และการทับของรูปโปรไฟล์เป็นแนวทางปฏิบัติจากคู่มือขนาดภาพ
  ไม่ใช่ข้อกำหนดทางการของ Meta — ตรวจพรีวิวในเพจจริงก่อนบันทึก
- TikTok: รูปโปรไฟล์ 200×200 (สูงสุดที่แนะนำ) — [TikTok Help](https://support.tiktok.com/)
- Shopee: Shop Cover 1200×675 — [Shopee Seller Education](https://seller.shopee.sg/edu/article/2416/adding-decoration-components)
  · Shop Banner 1200×300 เป็นขนาดที่ใช้ทั่วไป · Shopee ไม่ได้ประกาศขนาดโลโก้ร้านเป็นตัวเลขกลาง
  500×500 จึงเป็นสี่เหลี่ยมจัตุรัสที่คมพอและอัปได้ทั้ง Seller Centre/แอป

**ยังไม่ได้ทดสอบ:** ชุดนี้ตรวจด้วยการจำลองการครอปและโซนปลอดภัยในเครื่องแล้ว แต่ยังไม่ได้อัปโหลดกับเพจ/บัญชีจริง
(เวิร์กสเปซนี้ไม่มีบัญชีและโทเคน) — หลังอัปโหลดจริงให้ตรวจพรีวิวบนมือถืออีกครั้ง โดยเฉพาะหน้าปก Facebook
และ Shop Cover เพราะแพลตฟอร์มอาจครอปต่างจากที่จำลอง
