# Kopwang Prompt System — สคริปต์ → ภาพ → วิดีโอ → ปักตะกร้า

ระบบสร้างพร้อมต์สำหรับคอนเทนต์ 30 วันของแคมเปญ Kopwang ครอบคลุมทั้ง Facebook, TikTok และ Shopee
โดยทุกวันจะมีพร้อมต์ 3 ขั้นที่ส่งต่อกันได้ และมีช่วง **สาธิตการใช้สินค้า** กับ **การปักตะกร้า/ลิงก์สินค้า**
ระบุไว้ชัดเจนในทุกแพลตฟอร์ม

```
data/content_seeds.json ─┐
content/plan.json        ─┼─► scripts/build_prompts.py ─► prompts/generated/day-NN.md + .json
prompts/system.json      ─┘                                    │
                                                               ├─► (1) เขียนสคริปต์  → LLM
                                                               ├─► (2) สร้างภาพ     → Midjourney / FLUX / SDXL
                                                               └─► (3) สร้างวิดีโอ  → Veo / Sora / Runway / Kling / Luma
                                                                        ↓
                                                          ตัดต่อ + เติมข้อความไทย + ปักตะกร้าในแพลตฟอร์ม
```

## ใช้งาน 3 นาที

```bash
# 1) สร้าง/อัปเดตพร้อมต์ทั้ง 30 วัน
python3 scripts/build_prompts.py

# 2) เปิดสารบัญแล้วเลือกวัน
#    prompts/generated/index.md
```

ขั้นตอนต่อวัน:

1. เปิด `prompts/generated/day-NN.md` แล้วคัดลอก **พร้อมต์เขียนสคริปต์** ของแพลตฟอร์มที่ต้องการไปวางในแชต AI
   (ChatGPT / Claude / Gemini) — จะได้ JSON ที่มี `voice_over`, `onscreen_text`, `shot_list`
2. เอาคำอธิบายช็อตจาก JSON ไปใช้กับ **พร้อมต์สร้างภาพ** ในตารางของวันนั้น (พร้อมต์เป็นภาษาอังกฤษ + negative prompt)
3. เอาสคริปต์และภาพไปใช้กับ **พร้อมต์สร้างวิดีโอ** แล้วตัดต่อจริง — ข้อความไทยให้เติมในโปรแกรมตัดต่อ
   ด้วยฟอนต์ `Noto Sans Thai` ไม่ต้องให้โมเดลวิดีโอสะกดไทยเอง
4. ปักตะกร้า/ลิงก์สินค้าตามตาราง "ปักตะกร้า / ลิงก์สินค้า" ของแพลตฟอร์มนั้น

ไฟล์ `day-NN.json` มีข้อมูลชุดเดียวกันแบบเครื่องอ่าน (`prompts.json` รวมทุกวัน) สำหรับทำไปป์ไลน์อัตโนมัติ

## ปักตะกร้า/ลิงก์สินค้า แยกตามแพลตฟอร์ม

| แพลตฟอร์ม | กลไก | จังหวะ | ทางสำรองถ้ายังทำไม่ได้ |
|---|---|---|---|
| Facebook | ติด Product tag จาก Facebook Shop + ปักหมุดคอมเมนต์ลิงก์ Line OA | ติดป้ายตอนโพสต์ และปักหมุดคอมเมนต์ทันที | ปักหมุดคอมเมนต์ Line OA แล้วพูดว่า "ทักไลน์ในคอมเมนต์ปักหมุด" |
| TikTok | แนบสินค้า TikTok Shop (Product link) ให้ไอคอนตะกร้าเหลืองติดกับคลิป | ให้ตะกร้าปรากฏตั้งแต่ช่วงสาธิตสินค้า และคงอยู่จนจบ | ปักหมุดคอมเมนต์ Line OA และพูดถึงในคลิป |
| Shopee | แนบสินค้าใน Shopee Video หรือปักตะกร้าใน Shopee Live เฉพาะลิสต์ที่อนุมัติ | แนบตะกร้าตั้งแต่เปิดคลิป และพูดซ้ำช่วงท้าย | ใช้แชทร้าน + โปรไฟล์ชี้ไป Line OA โดยไม่วางไฟล์ในลิสต์ |

> ⚠️ **อีบุ๊กกับ Shopee:** `setup/03-shopee.md` ระบุว่า Shopee ยังไม่ยืนยันว่าขายไฟล์อีบุ๊กได้
> ต้องได้คำยืนยันเป็นลายลักษณ์อักษรก่อนตั้งลิสต์ ระหว่างนี้ให้ปักตะกร้าเฉพาะสินค้าจับต้องได้
> ที่เกี่ยวข้อง (เช่น สมุดงานพิมพ์) หรือใช้แชทร้านเป็นทางสำรอง
>
> ⚠️ **TikTok Shop:** ต้องมีบัญชี TikTok Shop Seller ที่อนุมัติแล้ว และสินค้าอยู่ในสถานะเผยแพร่
> ถ้าขายไฟล์ดิจิทัล ต้องตรวจข้อกำหนดของ TikTok Shop ก่อนตั้งลิสต์เช่นกัน

ทุกพร้อมต์จึงมี "ทางสำรอง" ติดมาด้วยเสมอ เพื่อให้ถ่ายทำได้แม้ตะกร้ายังไม่พร้อม

## สาธิตการใช้สินค้า

ทุกวันมีช็อต `demo` บังคับอยู่ในโครงเรื่อง พร้อมต์จะสั่งให้โชว์อย่างน้อย:

- เปิดสารบัญให้เห็นครบทุกบท
- พลิกหน้า 3-4 บทที่คนสนใจมากที่สุด
- เปิดเทมเพลตคอนเทนต์ 30 วัน แล้วชี้ช่องที่ต้องกรอก
- เปิดสคริปต์ตอบแชท 12 สถานการณ์ 1 หน้า
- เปิดตารางติดตามผล 4 ตัวเลข แล้วกรอกตัวอย่าง 1 แถว

**วิธีถ่าย:** อัดหน้าจอ (screen record) หรือถ่ายมือถือถือไฟล์จริง/สมุดงานพิมพ์
**ห้ามในช็อตสาธิต:** ข้อมูลลูกค้าโดยไม่ขออนุญาต · ยอดเงิน/สลิปของผู้อื่น · การอ้างว่าทุกคนจะได้ผลเหมือนกัน

โมเดลวิดีโอไม่รู้จักไฟล์จริงหรือหน้าจอ E-Book ของคุณ ให้ใช้โมเดลช่วยเฉพาะ B-roll หรือฉากประกอบ
ส่วนช็อตสาธิตให้ถ่ายเองแล้วค่อยตัดต่อ

## ข้อห้ามที่ทุกพร้อมต์ย้ำไว้

- ห้ามใช้คำสัญญารายได้หรือผลลัพธ์เกินจริง (รายการคำต้องห้ามอยู่ใน `system.json` → `safety.banned_claims`)
- ห้ามภาพธนบัตร เหรียญ ทองคำ หรือกราฟกำไร
- ถ้ามีลิงก์สินค้า/ตะกร้า ให้บอกตรง ๆ ว่าเป็นลิงก์ของร้าน และไม่สัญญาผลลัพธ์จากการซื้อ
- ข้อความรีวิวหรือภาพลูกค้าใช้ได้หลังขออนุญาตแล้วเท่านั้น

## รันพร้อมต์กับโมเดลจริง (Gemini)

ขั้นสคริปต์รันอัตโนมัติได้ด้วย `scripts/gemini_prompt_runner.py` (REST ผ่าน stdlib — ไม่ต้องติดตั้งไลบรารีเพิ่ม)

```bash
cp .env.example .env          # ใส่ GEMINI_API_KEY=... (ขอ key: https://aistudio.google.com/apikey)
python3 scripts/gemini_prompt_runner.py --list-models
python3 scripts/gemini_prompt_runner.py --day 1 --platform tiktok --dry-run
python3 scripts/gemini_prompt_runner.py --day 1 --platform tiktok
```

ผลลัพธ์ไปที่ `content/ai-drafts/day-NN-<platform>.{md,json}` และบันทึกประวัติที่ `state/gemini-runs.jsonl`
ตัวรันตรวจให้ก่อนเขียนไฟล์: ฟิลด์ครบ (`voice_over`, `onscreen_text`, `shot_list`, `caption`, `hashtags`),
ความยาวแคปชันตามเพดานของแพลตฟอร์ม และคำต้องห้าม — ถ้าไม่ผ่านจะไม่เขียนไฟล์

ขั้นภาพและวิดีโอยังไม่มีตัวรันในรีโปนี้ เพราะเป็น API คนละแบบ (Midjourney / Veo / Runway ฯลฯ)
ใช้พร้อมต์จากไฟล์ `.md` กับเครื่องมือนั้นโดยตรง

## แก้ไขระบบ

| ต้องแก้อะไร | แก้ที่ | แล้วทำอะไรต่อ |
|---|---|---|
| หัวข้อ/ฮุก/ประเด็น/บีตของวัน | `data/content_seeds.json` | `python3 scripts/generate_plan.py` → `python3 scripts/build_prompts.py` |
| วันที่/เวลา/จำนวนวันของแคมเปญ | รัน `generate_plan.py --start-date ...` | `python3 scripts/build_prompts.py` |
| สไตล์ภาพ สี ข้อห้าม คำพูดปักตะกร้า อัตราส่วนภาพ | `prompts/system.json` | `python3 scripts/build_prompts.py` |
| ตรวจว่าพร้อมต์ที่ commit ตรงกับข้อมูลต้นทาง | — | `python3 scripts/build_prompts.py --check` |
| ตรวจระบบทั้งหมด | — | `python3 tests/prompt_system_test.py` |

`prompts/generated/` เป็นไฟล์ที่สร้างใหม่ได้เสมอ — แก้ต้นทางแล้วรันสคริปต์ ไม่ต้องแก้ไฟล์ผลลัพธ์ด้วยมือ

## ใช้กี่พร้อมต์ต่อวัน

ในไฟล์ `day-NN.md` ของแต่ละวันมี

- พร้อมต์สคริปต์ 3 อัน (Facebook / TikTok / Shopee) — ใช้จริง 1 อันต่อช่องทางที่โพสต์
- พร้อมต์ภาพ 3-6 อันต่อแพลตฟอร์ม (ตามช็อตในโครงเรื่อง) — เลือกใช้เท่าที่จำเป็น
- พร้อมต์วิดีโอ 3 อัน (หนึ่งอันต่อแพลตฟอร์ม) — ใช้เป็นโครงให้โมเดลวิดีโอหรือทีมตัดต่อ
- ชุดปักตะกร้า 3 ชุด (หนึ่งอันต่อแพลตฟอร์ม) — ใช้เป็นเช็กลิสต์ตอนโพสต์
