# 03 — Shopee: เปิดร้าน และเรื่องสำคัญเรื่องการขายอีบุ๊ก

> ⚠️ **อ่านส่วนนี้ก่อนตั้งลิสต์ทุกครั้ง**
> Shopee แบ่ง "สินค้าดิจิทัล" เป็นกลุ่มที่มีแบบแผนชัดเจน เช่น **Shopee E-Service** และ **Shopee E-Voucher**
> (การจอง บริการเดิมเงิน ค่าบริการรายเดือน บัตรกำนัลการศึกษา ฯลฯ)
> **การขายไฟล์อีบุ๊กให้ดาวน์โหลด ไม่ได้ถูกระบุว่าเป็นประเภทสินค้าที่รองรับ** ในเอกสารของ Shopee
> และ Shopee ระบุว่าผู้ขายไม่สามารถลงขายบริการได้โดยตรง รวมทั้งลิสต์สินค้าดิจิทัล/บริการที่ไม่ได้รับอนุญาตอาจถูกลบ
>
> **สิ่งที่ต้องทำ:** ถ้าจะขายบน Shopee ต้องได้คำยืนยันเป็นลายลักษณ์อักษรจาก Shopee ก่อน
> ว่าอีบุ๊กของคุณเข้าข่ายประเภทใด และควรตั้งลิสต์อย่างไร — **อย่าออกแบบธุรกิจโดยฝากความหวังไว้กับลิสต์อีบุ๊กบน Shopee**

---

## บทบาทของ Shopee ในแผน 30 วันนี้

ให้ Shopee ทำหน้าที่เป็น **ช่องทางสร้างความน่าเชื่อถือและหาลูกค้าใหม่** ไม่ใช่ช่องทางส่งมอบไฟล์หลัก

```
Shopee (เจอสินค้า + แชทร้าน) ──► Line OA @kopwang ──► ส่งมอบไฟล์ E-Book ──► ขอรีวิว
```

## ขั้นที่ 1 — สมัครผู้ขาย

1. เข้า `https://seller.shopee.co.th` → สมัครด้วยบัญชี Shopee
2. เลือกประเภทผู้ขาย:
   - **บุคคลธรรมดา:** สัญชาติไทย อายุ 20 ปีขึ้นไป มีบัตรประชาชนไทย
   - **นิติบุคคล:** ต้องมีเอกสารจดทะเบียนธุรกิจ
3. ยืนยันตัวตน (KYC) ตามที่ระบบร้องขอ และกรอกข้อมูลร้าน
4. ผูกบัญชีธนาคารสำหรับรับเงิน — **ชื่อบัญชีต้องตรงกับชื่อผู้ขาย/ชื่อนิติบุคคล**

## ขั้นที่ 3 — เลือกของที่จะขายบน Shopee อย่างปลอดภัย

เรียงจากความเสี่ยงต่ำไปสูง:

| ระดับ | แนวทาง | หมายเหตุ |
|---|---|---|
| แนะนำ | สินค้าจับต้องได้ที่เกี่ยวข้องกับแคมเปญ เช่น สมุดงานพิมพ์ (Workbook) ของระบบ 30 วัน, ชุดโน้ต/สติกเกอร์แบรนด์ | เป็นสินค้าปกติ มีของส่งจริง ความเสี่ยงต่ำ |
| หาข้อมูลก่อน | E-Voucher / E-Service ที่ Shopee รองรับ หรืออีบุ๊กที่ Shopee ยืนยันแล้วว่าเข้าข่าย | ต้องได้คำยืนยันจาก Shopee ก่อนตั้งลิสต์ |
| หลีกเลี่ยง | ลงลิสต์เป็น "ไฟล์ PDF ส่งทางแชท" หรือ "ลิงก์ดาวน์โหลด" | เสี่ยงถูกลบและเสียประวัติร้าน |

ร้านสามารถใช้เป็น "หน้าต่างให้ข้อมูล" ได้ เช่น อธิบายว่าระบบ 30 วันคืออะไร มีอะไรให้บ้าง และให้ลูกค้าทักแชทเพื่อรับรายละเอียด — โดย**ไม่วางไฟล์ในลิสต์**

## ขั้นที่ 4 — งานร้านประจำวัน (ทำมือ)

ตารางงาน 30 วันอยู่ใน `content/shopee-30days.md` และอยู่ใน `content/30-day-plan.csv` (คอลัมน์ `platform = shopee`)

รอบที่แนะนำ:

- **09:30** อัปเดตร้าน: รูป คำโปรย สินค้าปักหมุด (งานวันละ 15 นาที)
- **12:00 และ 21:00** เช็กแชท 2 รอบ ตอบภายใน 1 ชั่วโมงเพื่อรักษาคะแนนร้าน
- **ทุกสัปดาห์** ตรวจสถิติ: สินค้าที่คนเข้าชมสูงสุด 3 อันดับ และสินค้าที่ไม่มีคนเข้าเลย

## ขั้นที่ 5 — Shopee Open Platform (ตัวเลือก ไม่จำเป็นต้องใช้ตอนเริ่ม)

ถ้าต้องการจัดการสินค้า/ออเดอร์เป็นระบบในอนาคต:

- ต้องมีบัญชีนักพัฒนาบน Shopee Open Platform + แอป + การอนุญาตสิทธิ์ร้าน
- เอนด์พอยต์ที่เกี่ยวข้อง เช่น `product.add_item` (สร้างสินค้า) และ `order.get_order_list` (ดูรายการออเดอร์)
- **ข้อควรระวัง:** API ไม่ได้ทำให้สินค้าที่ผิดนโยบายขายได้ — สิทธิ์ API และความสามารถในการขายสินค้าเป็นคนละเรื่องกัน
